# samtgb
Sam Irving's text based adventure game for CS30

## Description 
# Nightmare at 30,000 feet
In this horror text based game inspired by the famous Twilight Zone episode
>"Nightmare at 30,000 feet"

The player wakes up on a plane in sky, completely alone...or are you.  Explore the plane, survive the danger, and figure out what is going on?

# Instalation 
Python 3.7 is needed to run the game. [Python 3.7](https://www.python.org/downloads/) please click the link to download the proper software.

## Run the Program

```python
python game.py
```
